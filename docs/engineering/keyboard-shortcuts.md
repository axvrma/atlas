# Workspace keyboard reference

- Cmd/Ctrl K: open the command menu, then search and Tab to a result.
- Cmd/Ctrl Z: undo graph edits. Shift Cmd/Ctrl Z or Ctrl Y: redo.
- Cmd/Ctrl S: explicitly save browser state.
- Cmd/Ctrl C and V: copy selected nodes and paste at an offset.
- Cmd/Ctrl D: duplicate selected nodes.
- Delete/Backspace: remove selected canvas nodes or edges through XYFlow.
- Escape: clear editor selection or dismiss an open overlay.

Editor shortcuts ignore focused text inputs and selects. Shift/Cmd/Ctrl supports canvas multiselection. Canvas controls offer zoom and fit. The accessible node list offers a nonspatial alternative: select/configure nodes, remove connections, choose source/target and condition branch, and add a connection using native controls. Add nodes using palette buttons. Connections are validated before simulation.
